# Object controls — contracts

Node-view objects use the attached `OverlayIconRow` corner; tables are the measured exception and use
the table lane. A missing control is absence, not a disabled row. Where a command is visible but
refused, use the shared blocked-row reason.

Diagram rendering is token-time and provider-keyed. Source identity stays a stable document address,
never a signed URL.

Replace operations hold their target through confirmation and keep the command's undo semantics.

A dialog doesn't own a second object selection, and outcomes render through the chrome registry.
