# Completion contracts

## Browser projection

Other Works remain authority rows until explicitly activated. The browser
delegates cold Work acquisition to the catalog owner and doesn't fetch
recursively, retain catalog entries, or turn availability requests or wake
notifications into browse rows. URI segments are completed by the host's canonical
callback, not reconstructed from display labels.

## Menu lifecycle

The driver ticket is `(sessionId, generation)`; close consumes the complete
ticket. A host may keep an empty session while loading or showing an empty state,
but ordinary open needs selectable rows. A same-session refresh may preserve the
stable active row ID. A host refusal is skipped rather than highlighted.

The host lease is released exactly once and removes both ordinary key bindings
and retreat.
