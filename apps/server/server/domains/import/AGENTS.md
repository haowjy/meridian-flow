# Import

A selected folder creates a new tree. Loose files land beside existing children.
This domain owns durable selection identity, allocation and landing receipts,
not context storage or Yjs admission. Notes remain unconverted until the
Obsidian-conversion phase.

Keep planning pure. Storage adapters join the repository's ambient transaction.
Resolve parents and placeholders by identity after moves; never recreate a
writer-deleted node. Finish is terminal.
