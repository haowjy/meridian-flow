# Flows

Each flow follows one writer action through the running code, call by call, and names the file where
each step happens. The participants are boxes on the map; click one in a diagram's page to see it.
A step marked **not traced** is one the author did not follow through the source.

- [A message becomes an edit](message-becomes-edit.md): the writer sends a message and the model edits a document.
- [Opening a document](opening-a-document.md): a tab connects to the document's live room.
- [An import](an-import.md): a folder of files becomes documents.

The same stories as pictures of the parts: [system](../system.md), [server](../server.md), [app](../app.md).
