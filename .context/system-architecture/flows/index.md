# Flows

Each flow follows one writer action through the running code, call by call, and names the file where
each step happens. The participants are boxes on the map. A flow sits under the journey step it
traces: the Journeys page lists these under "What happens underneath", and the step links its flow.

- [A message becomes an edit](message-becomes-edit.md): traces "Ask for an edit" in [Draft with the model](../journeys/draft-with-the-model.md): the model's edit to a document.
- [Opening a document](opening-a-document.md): traces "Open a chapter" in [Start a project](../journeys/start-a-project.md): the tab connects to the document's live room.
- [An import](an-import.md): traces "Watch the import run" in [Start a project](../journeys/start-a-project.md): a folder of files becomes documents.
