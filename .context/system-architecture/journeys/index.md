# Writer journeys

Two paths through the product, each a row of steps with what the writer does and sees, the boxes on
the [system](../system.md), [server](../server.md) and [app](../app.md) pages that carry the
step, and the state machines involved. They describe the `ux-v1` interface (PR #1304), so they
change when it merges; each step says whether it comes from the code or from the PR body only.

- [Draft with the model](draft-with-the-model.md): choose a Work, ask the model to write, review its drafts, apply or undo.
- [Start a project](start-a-project.md): sign in, create a project, import a manuscript, open a chapter and write.
