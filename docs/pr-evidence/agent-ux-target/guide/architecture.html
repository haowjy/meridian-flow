Architecture

Compile, bind, prepare, then reuse the turn Flow already has.

Mars owns portable source semantics. Flow owns chat binding, Project authorization, fixed Work context, effective tool policy, model execution, and manuscript mutation. Five structural additions are sufficient.

One direction of authority keeps policy from splitting

Required addition

Four interfaces are earned by volatility, not ceremony

Work is fixed context, not a permission grant. The source can request actions but cannot grant itself access or broaden an explicit host restriction.

The design uses small, proven patterns instead of a capability platform

Required addition

Compile then execute

Parse and validate portable source once. Runtime consumes a closed immutable value.

Functional core, imperative shell

Normalization, digesting, policy intersection, and availability are pure. Persistence, gateway calls, and Yjs mutation are effects.

Immutable revision reference

Threads bind a revision ID, never a slug, display name, or activation pointer.

Policy and mechanism stay separate

EffectiveToolPolicy decides. Tool handlers execute. The same value advertises and blocks dispatch.

Child Agents are an explicit later extension, not hidden root infrastructure

Later extension

After root Agent v1 ships, child edges resolve to exact definition revisions. Children inherit Project and fixed Work, and their effective policy can only attenuate the parent. A bounded foreground spawn reports through the parent transcript.

Do not add child transcript chrome, helper cards, task center, workflow graph, a durable run store, or resumable orchestration until observed background and resume needs earn those systems.
