Removal inventory

The smallest honest system deletes the second product hiding beside the first.

Root Agent v1 deliberately removes duplicate launch paths, second run evidence, mutable identity, compatibility ceremony, and early distribution. This is a target inventory, not a list of optional cleanups.

Ordinary turns do not grow generic evidence rows

Data loses mutable execution identity and early distribution state

Deleted behavior

Remove mutable current definition rows, user or Project overlays, active revision behavior pointers, slug thread binding, prompt snapshots treated as identity, compatibility caches, approval grants for native writing, registry sources, publisher keys, artifact controls, and update activation records. Root v1 has immutable source and definition revisions, a future-chat catalog pointer, and an immutable thread binding.

Future work remains named, but it does not arrive as invisible scaffolding

Later extension

Child Agents

Foreground spawn and report after root v1, with exact child revisions and attenuated policy.

Remote distribution

Only after deterministic local Mars round-trip, with separate identity, trust, update, and revocation decisions.

External effects

Only with connection binding, operation confirmation, suspension and resume, and effect receipt.

Rich revision management

Activation, diff, and rollback may later affect future chats. Existing bindings remain pinned.
